# HIPAA 业务伙伴协议

Cursor 为 Enterprise 客户支持 HIPAA 业务伙伴协议（BAA）。

根据 HIPAA 属于受覆盖实体或业务伙伴的组织，可以在 Enterprise 协议中请求 BAA。在向 Cursor 提交受保护健康信息（PHI）之前，必须签署 BAA。

## 请求 BAA

BAA 在 Enterprise 方案上提供。要请求一份：

1. [联系销售](https://cursor.com/contact-sales?source=docs-baa)
2. 告诉我们你需要 HIPAA BAA
3. 说明你是在评估 Cursor、从 Teams 方案迁移，还是已经在使用 Enterprise

### 请求 HIPAA BAA

联系销售，为 Cursor Enterprise 请求 BAA 支持。

## 在包含 PHI 的情况下使用 Cursor

HIPAA 实施与配置指南是 BAA 的一部分。它包含关于 Eligible Services、Eligible Models、必需控制措施和客户责任的当前细节。[在 Trust Center 请求访问](https://trust.cursor.com/resources?s=i7h69cmvekn7rag2pc9y4r\&name=cursor-hipaa-implementation-guide.pdf)。

BAA 不会自动使每个产品、配置或工作流都适合 PHI。你的组织有责任按照 BAA、HIPAA 要求和 HIPAA 指南来配置 Cursor 并指导用户。

在将 Cursor 与 PHI 一起使用之前：

- 与 Cursor 签署 Enterprise 协议和 BAA
- 查阅 Trust Center 中的 HIPAA 指南
- 在全组织启用并锁定 [Privacy Mode](https://cursor.com/docs/enterprise/privacy-and-data-governance.md#privacy-mode-enforcement)
- 培训用户只通过 Eligible Services 和已批准的工作流提交 PHI

第三方服务和集成不会自动被 Cursor 的 BAA 覆盖。你的组织仍有责任评估并配置与 Cursor 一起使用的任何第三方服务。

## Eligible Services

列出的 Eligible Services 对已在全组织启用并锁定 Privacy Mode 的 Enterprise 客户予以覆盖：

- 桌面 IDE，包括 Agent、Tab、Edit 和本地 Agent 模式
- Cloud Agents
- Cursor for iOS
- CLI
- Tab
- BugBot
- Automations

HIPAA 指南有关于 Eligible Services 和实施要求的最新细节。[在 Trust Center 请求访问](https://trust.cursor.com/resources?s=i7h69cmvekn7rag2pc9y4r\&name=cursor-hipaa-implementation-guide.pdf)。

## 常见问题

### 谁可以请求 BAA？

Enterprise 客户以及正在评估 Enterprise 的潜在客户可以为 Cursor 请求 BAA。这通常适用于作为受覆盖实体或业务伙伴的医疗组织和供应商。

### Teams 上是否提供 BAA 支持？

BAA 支持在 Enterprise 上提供。如果你的组织目前使用 Teams 方案，请[联系销售](https://cursor.com/contact-sales?source=docs-baa)，讨论迁移到 Enterprise 并请求 BAA。

### 可以在 BAA 签署之前提交 PHI 吗？

不可以。在 Enterprise 协议和 BAA 签署，并且组织完成所需的实施步骤之前，不要向 Cursor 提交 PHI。

### 哪些 Cursor 服务被覆盖？

你签署的 BAA 和 HIPAA 指南列出了针对 PHI 覆盖的 Eligible Services。[在 Trust Center 请求访问](https://trust.cursor.com/resources?s=i7h69cmvekn7rag2pc9y4r\&name=cursor-hipaa-implementation-guide.pdf)。

### 哪些模型被覆盖？

HIPAA 指南列出当前的 Eligible Models。[在 Trust Center 请求访问](https://trust.cursor.com/resources?s=i7h69cmvekn7rag2pc9y4r\&name=cursor-hipaa-implementation-guide.pdf)。

### Cursor 的 BAA 是否覆盖第三方模型提供商或集成？

Cursor 的 BAA 不会自动覆盖第三方服务。在提交 PHI 之前，请查阅已批准的配置、模型提供商设置、集成用法以及 HIPAA 指南。

### 如何获取安全与合规文档？

访问 [Trust Center](https://trust.cursor.com/)，请求访问可用的安全与合规文档。
