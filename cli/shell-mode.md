# Shell Mode

Shell Mode 直接从 CLI 运行 shell 命令，而无需离开对话。把它用于快速、非交互的命令，带有安全检查，并把输出显示在对话中。

[Media](/docs-static/images/cli/shell-mode/cli-shell-mode.mp4)

## 命令执行

命令在你的登录 shell（`$SHELL`）中运行，使用 CLI 的工作目录和环境。把命令串起来以在其他目录中运行：

```bash
cd subdir && npm test
```

## 输出

较大的输出会自动截断，长时间运行的进程会超时，以保持性能。

## 限制

- 命令在 30 秒后超时
- 不支持长时间运行的进程、服务器和交互式提示
- 使用简短的非交互命令以获得最佳结果

## 权限

命令在执行前会对照你的权限和团队设置进行检查。详细配置见[权限](https://cursor.com/docs/cli/reference/permissions.md)。

管理员策略可能会阻止某些命令，带有重定向的命令不能在行内加入允许列表。

## 使用建议

Shell Mode 适合状态检查、快速构建、文件操作和环境查看。

避免长时间运行的服务器、交互式应用，以及需要输入的命令。

每条命令独立运行——使用 `cd <dir> && ...` 在其他目录中运行命令。

## 故障排除

- 如果命令挂起，用 Ctrl+C 取消，并加上非交互标志
- 当提示权限时，批准一次，或用 Tab 加入允许列表
- 对于被截断的输出，用 Ctrl+O 展开
- 要在不同目录中运行，使用 `cd <dir> && ...`，因为目录更改不会保留
- Shell Mode 支持 `$SHELL` 变量中的 zsh 和 bash

## 常见问题

### \`cd\` 会在多次运行之间保留吗？

不会。每条命令独立运行。使用 `cd <dir> && ...` 在不同目录中运行命令。

### 我可以更改超时吗？

不可以。命令限制为 30 秒，并且不可配置。

### 权限在哪里配置？

权限由 CLI 和团队配置管理。使用决定横幅把命令加入允许列表。

### 如何退出 Shell Mode？

在输入为空时按 Escape，在空输入上按 Backspace/Delete，或按 Ctrl+C 清除并退出。
