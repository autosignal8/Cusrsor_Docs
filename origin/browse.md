# 浏览与搜索

Origin 目前以早期 beta 发布。你可以创建仓库，用 git 推送和拉取，从 GitHub 镜像，浏览并搜索代码，打开并合并 pull request，并与你的 Cursor 团队共享。

在 [cursor.com/codebase](https://cursor.com/codebase) 打开仓库，即可在 **Code** 标签页浏览文件、搜索代码并查看提交历史。

## 文件夹与文件

在 **Code** 上，于树中浏览目录并打开文件。从页眉中的分支控件切换分支。绿色的 **Code** 按钮会打开 HTTPS 和 Origin CLI 克隆设置。

![Origin 仓库的 Code 标签页，包含文件树和文件内容](/docs-static/images/origin/browse-files.png)

## 搜索

用 **Go to file**（快捷键 `T`）或仓库页眉中的搜索框查找文件和代码匹配。

![Origin 仓库中搜索文件和代码](/docs-static/images/origin/browse-search.png)

## 分支历史与提交

在 **Code** 中，打开当前分支的提交历史。选择一次提交即可查看其消息、元数据和已更改的文件。打开历史之前，用分支控件在分支之间移动。要看某一个人的提交，在分支控件旁的 **All authors** 中选择此人，或输入邮箱。单个文件或文件夹的历史上不提供作者筛选。

## 相关

仓库页眉在 **Code** 旁边还有 **Pull requests** 和 **Settings** 标签页：

- [Pull requests](https://cursor.com/docs/origin/pull-requests.md) - 打开、审查并合并 pull request
- [设置](https://cursor.com/docs/origin/settings.md) - 同步状态、访问权限、规则与保护，以及 apps
