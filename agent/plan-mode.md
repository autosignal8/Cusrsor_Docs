# Plan Mode

Plan Mode 在写任何代码之前创建详细的实现计划。Agent 会研究你的代码库、提出澄清问题，并生成一份你可以在构建前编辑的计划。

在聊天输入框按 Shift+Tab 可切换到 Plan Mode。当你输入表明任务复杂的关键词时，Cursor 也会自动建议使用它。

## 它如何工作

1. Agent 提出澄清问题，以理解你的需求
2. 研究你的代码库，收集相关上下文
3. 创建一份全面的实现计划
4. 你通过聊天或 Markdown 文件审查并编辑计划
5. 准备好后点击以构建该计划

计划默认保存在你的主目录。点击 “Save to workspace” 可把它移到工作区，以便日后参考、与团队共享，以及作为文档。

## 何时使用 Plan Mode

Plan Mode 最适合：

- 有多种可行做法的复杂功能
- 触及许多文件或系统的任务
- 需求尚不清楚、需要先探索才能理解范围的情况
- 你希望先审查方案的架构决策

对于快速改动，或你已经做过很多次的任务，直接进入 Agent 模式即可。

## 从计划重新开始

有时 Agent 构建出的东西与你想要的不符。与其用后续提示词试图修补，不如回到计划。

还原改动，把计划改得更具体，说明你需要什么，然后再次运行。这通常比修复一个进行中的 Agent 更快，结果也更干净。

对于更大的改动，多花时间做出一份精确、范围清楚的计划。难的部分往往是弄清**应该**做哪项改动。指令正确之后，把实现委派给 Agent。

## 切换模式

- 使用 Agent 中的模式选择下拉菜单
- 按 Shift+Tab 快速切换
